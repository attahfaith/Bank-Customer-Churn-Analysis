# Bank-Customer-Churn-Analysis

### Project Overview

This project analyzes customer churn behaviour across 10,00 bank customers in France, Germany,and Spain. The aim is to identify the key factors driving customer attrition and provide actionable recommendations to improve retention. The dataset contains 14 variables including customer demographics, account information and churn status

### Data Source

The dataset used for this analysis was obtained from "KAGGLE BANK Customer Churn data.CSV" file, representing a real bank customer information.

### Tools

- Microsoft Excel - Data cleaning,Pivot tables, dashboard
- Formulas used - IF,COUNTIF,AVERAGEIF,COUNTA

### Data cleaning\preparation

- Verified 14 columns for missing values
- Created Age Group helper column using IF formula
- Created Balance Group column using IF
- Formatted Balance Column to Currency

### Exploratory Data Analysis

EDA involves exploring the Bank Customer Churn data to answer key questions, such as;

- What is the overall churn rate?
- Which geography has the most customers?
- Does gender affect churn rate?
- Which age group churn the most?
